# ATLAS Align Step Type Reference

> Generated by `node tools/build-copilot-agent.mjs` from the ATLAS Align repository. Do not edit by hand.
> Engine 1.19.0, File Utility contract v3.

This file lists the step types, action kinds, operators and editor controls that ship with ATLAS Align. Step types and action kinds published later in the Step Type Builder are **not** here: look for them in the SharePoint step type folder first. A type there with the same `id` and a higher `version` replaces the one below.

## 1. Step types for new audits

| `step_type`         | `type`      | Label                | Use for                                                                             |
| ------------------- | ----------- | -------------------- | ----------------------------------------------------------------------------------- |
| `reference_source`  | `source`    | Reference Source     | Start working with a source file. Add one per source, before any step that uses it. |
| `create_column`     | `create`    | Create Column        | Create or populate an output column.                                                |
| `if_then`           | `if`        | IF / THEN            | Add conditional IF / THEN logic.                                                    |
| `join`              | `join`      | Join / Union Sources | Combine sources with Join or Union logic.                                           |
| `format_field`      | `transform` | Format Field         | Format values in a selected field.                                                  |
| `split_field`       | `transform` | Split Field          | Split a field into a derived output.                                                |
| `sort_records`      | `transform` | Sort Records         | Sort records by one or more fields.                                                 |
| `remove_duplicates` | `transform` | Remove Duplicates    | Remove records whose selected columns all match.                                    |

The params tables list what each type stores. When you write an audit, follow the recipes in `AUDIT_JSON_FORMAT.md`: for some types (Join, Sort Records, Remove Duplicates) the import builds the stored list params, such as `join_keys_json`, from the simpler params the recipe uses.

## 2. Legacy step types

| `step_type`     | Label         | Use instead                                                                                    |
| --------------- | ------------- | ---------------------------------------------------------------------------------------------- |
| `else`          | ELSE          | `if_then` with an ELSE branch (`else` steps are still written by the import for ELSE branches) |

## 3. Action kinds (`then_action_type`)

An `if_then` (or `else`) step does one action kind when its conditions are true.

| `then_action_type`            | Picker label                        | What it does                              | Params it needs                                                           | File Utility                                                                                                                           |
| ----------------------------- | ----------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `freeform`                    | Freeform Text (legacy)              | Describe the action in words.             | `then_action`                                                             | partial: a container for child steps, or the exact text 'DISPLAY "text" in column "name"' or 'Do Not Display'; other text is a blocker |
| `set_column_value`            | Set Column Value from Field         | Copy a field into a column.               | `then_target_column`, `then_value_field`                                  | supported                                                                                                                              |
| `set_column_string_transform` | Set Column to String Transformation | Write part of a text value into a column. | `then_target_column`, `then_string_source_field`, `then_string_operation` | partial: first_characters, last_characters, character_count                                                                            |
| `set_column_calculation`      | Set Column to Calculated Value      | Write a calculation into a column.        | `then_target_column`, `then_value_field`                                  | supported                                                                                                                              |
| `display_text`                | Display Text Response in Column     | Write a text response in a column.        | `then_text`, `then_output_column`                                         | supported                                                                                                                              |
| `display`                     | Display / Do Not Display            | Display the records.                      |                                                                           | supported                                                                                                                              |
| `do_not_display`              | Do not display                      | Leave the records out.                    |                                                                           | supported                                                                                                                              |

## 4. Condition operators

Write operators exactly as shown, lowercase. The value mode decides which operators a condition may use.

| `operator`                    | Value modes              | Opposite (ELSE)               | Also read as   | Runs in File Utility |
| ----------------------------- | ------------------------ | ----------------------------- | -------------- | -------------------- |
| `is equal to`                 | values, field, parameter | `is not equal to`             |                | Yes                  |
| `is not equal to`             | values, field, parameter | `is equal to`                 |                | Yes                  |
| `contains`                    | values, field            | `does not contain`            |                | Yes                  |
| `does not contain`            | values, field            | `contains`                    |                | Yes                  |
| `starts with`                 | values, field            | `does not start with`         |                | Yes                  |
| `does not start with`         | values, field            | `starts with`                 |                | Yes                  |
| `ends with`                   | values, field            | `does not end with`           |                | Yes                  |
| `does not end with`           | values, field            | `ends with`                   |                | Yes                  |
| `is greater than`             | values, field, parameter | `is less than or equal to`    |                | Yes                  |
| `is greater than or equal to` | values, field, parameter | `is less than`                |                | Yes                  |
| `is less than`                | values, field, parameter | `is greater than or equal to` |                | Yes                  |
| `is less than or equal to`    | values, field, parameter | `is greater than`             |                | Yes                  |
| `is blank/null`               | blank                    | `is not blank/null`           | `is blank`     | Yes                  |
| `is not blank/null`           | blank                    | `is blank/null`               | `is not blank` | Yes                  |
| `matches expression`          | expression               | `does not match expression`   |                | No (blocker)         |
| `does not match expression`   | expression               | `matches expression`          |                | No (blocker)         |
